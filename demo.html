What you are watching: the agent observes the screen, decides an action with a stated reason, acts, and the game returns a new screen and a score. That is the whole agent loop. The screen keeps changing and the reasons stay confident, yet the score never moves off zero — the same result a random baseline gets. This project's finding is that ~88% of the agent's moves are legal, non-repeating, screen-changing work that makes no progress, because the game states no goal for the loop to steer toward.
What am I looking at, and is it real?

Every frame, action, reason, and score here is read verbatim from a runs/*.recording.jsonl.gz file — one of the actual games the agent played. "Cells changed" and "score change" are recomputed from consecutive frames at build time, so a label can never disagree with the picture. Rebuild this page any time with py build_demo.py. The colours are the one presentational choice; the agent reasons over the raw numbers, not the hues.
